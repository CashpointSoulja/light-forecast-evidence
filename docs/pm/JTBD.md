# Jobs to be done

Hypotheses. None of these come from interviews; I have not run any.

| Job | When… | I want to… | So I can… |
|---|---|---|---|
| Inspect the forecast | it is Monday and I prepare the weekly call | see which commit and best-case deals lack evidence for their stage | challenge them in the call instead of after the quarter |
| Write the board narrative | I am preparing the board pipeline page | build it from a named revision with every total's denominator | say exactly what the number includes, and know when it has gone stale |
| Chase gaps | a deal is blocked | send the owner one specific next action with the source row | fix the evidence rather than argue about the category |
| Trust an import | I bring in a CRM export | see every rejected row and why, before anything is saved | avoid half-imported or formula-tainted data |
| Explain currency | deals are in several currencies | see which were converted, at what rate, and which were not | avoid hiding unconverted value inside a GBP total |
